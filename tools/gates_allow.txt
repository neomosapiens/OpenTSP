# Checks and recipes that no gate calls, each with a reason (tools/check_gates_wired.py reads this file; `just check-docs` runs it).
# Format: <path or recipe> | <reason> | <note>. Reasons: manual (run by hand when its area changes), long (more than about 20 minutes;
# run by hand before a release and recorded in the ledger), owner (the owner decides when it runs), ci (only a CI workflow runs it,
# and CI does not run in this repository). There is no scheduler, so there is no reason for a scheduled run. What a listed recipe
# runs needs no line of its own. An entry whose gate is wired later must be removed: the checker fails on it.
fmt | manual | rewrites files with rustfmt; `lint` is the check

coverage-iss | manual | coverage report of the ISS; not a check; run when its tests change
iss-tick | manual | every-cycle tick equality (about ten minutes); run before a change of the tick loop
iss-bench | manual | timing targets of the ISS on a quiet host; not a correctness gate

iss-perf-gate | manual | the timed A/B on a quiet host; the verdict tests run in check-docs
iss-perf-insn | manual | optional retired-instruction comparison; needs a distinct baseline and a working host instruction counter
iss-perf-baseline | owner | the stored benchmark baseline, updated on a quiet host with the change that moves it
iss-pgo | manual | builds a profile-guided binary; not a check
iss-replay-bucket | manual | the real bucket under single-bit faults; needs the benchmark inputs

vllm-surface | manual | the vLLM surface check (needs the vLLM environment)

iss-pgo-binding | manual | builds a profile-guided binding for serving; not a check
showcase-batch | manual | an interactive batch session of the showcase in the vLLM environment, with the real weights; `showcase-test` and `vllm-e2e` are the checks

showcase | manual | the interactive showcase session in the vLLM environment with the real weights; `showcase-test` and `vllm-e2e` are the checks
showcase-reference-full | manual | `showcase-reference` with the slow tests (the 8-layer text-sizing grid and the paged ISS tests, about ten minutes); a cold program cache adds generation time
